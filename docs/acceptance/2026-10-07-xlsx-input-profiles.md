# Приёмка явных профилей XLSX — 07.10.2026

Этап 3 [плана исправлений](../superpowers/plans/2026-10-05-reqmap-coverage-remediation.md):
импорт двух форматов без изменения исходных книг. Проверка не вызывает модель,
`reqmap analyze` или инфраструктуру и не измеряет функциональное покрытие.

## Контракт

Профиль `header` сохраняет прежнее адресование по точным заголовкам.
Новый `column_mode=position` явно задаёт буквы Excel A–XFD и
`data_start_row`. Смешивание режимов отклоняется. CLI и MCP используют общий
парсер и загрузчик. Новый профиль входит в сохранённые настройки MCP;
проверено восстановление сессии после удаления синтетического оригинала.
Существующие профили без новых полей сохраняют значения по умолчанию.

Импорт сохраняет каждую непустую строку, исходный текст, ID, координаты,
настроенные поля и подсказки. Повторный ID не удаляет строку. Формула в тексте
отклоняется, пустая ячейка пропускается, отсутствующая колонка диагностируется.
Автоматического распознавания позиционного профиля нет.

Группировка и orchestration не изменены. Синтетическая пара «действие Nova» /
«численное продолжение с тем же ID» сохраняет независимые строки: вторая
не получает родительский текст и остаётся неразобранной в canonical binding.
Это проверка границы контекста, а не решение произвольных продолжений русского текста.
