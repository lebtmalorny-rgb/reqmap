## Попытка запуска IDE

Открыт проект MCP в VS Code 1.135.0. Панель Codex показывала поле ввода и
выбранную модель `GPT-6 Astra Extra High`. При подготовке ввода средство
управления интерфейсом потеряло окно: `cgWindowNotFound`. Повторный выбор
приложения по bundle ID и сброс сеанса управления результата не дали.
VS Code при этом присутствовал в списке запущенных приложений.

Запрос не был вставлен/отправлен; новой сессии reqmap этой живой проверки нет.
Ошибка относится к доступу средства управления к окну и сама по себе не
доказывает сетевую ошибку, неисправность MCP или модели. Ожидается доступное
окно проекта с панелью Codex; после восстановления отправляется подготовленный
запрос, без изменения входа и ожиданий.

Локальные материалы находятся в `results/api-live-eval-2026-10-07/`:
`requirements.txt`, `prompt.txt`, `preflight.json`, `backend-baseline.json`.
В чат передаётся только путь к текстовому входу и порядок работы по skill;
контрольные ответы модели не сообщаются. После завершения необходимо отдельно
проверить журнал настоящего клиента, session IDs, исходные строки, атомы,
статусы и hashes пяти экспортированных файлов.
