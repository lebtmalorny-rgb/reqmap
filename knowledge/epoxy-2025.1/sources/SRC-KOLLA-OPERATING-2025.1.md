# Kolla-Ansible operating excerpt

- URL: https://docs.openstack.org/kolla-ansible/2025.1/user/operating-kolla.html
- Locator: `Tools versioning` and `Tips and Tricks / Kolla Ansible CLI`.
- Retrieved: 2026-08-20.

The versioned guide says Kolla-Ansible deploys images for the targeted OpenStack series and documents `kolla-ansible reconfigure -i INVENTORY` as the command used to reconfigure an OpenStack service. It distinguishes `genconfig`, which generates configuration without applying it by restarting containers.
