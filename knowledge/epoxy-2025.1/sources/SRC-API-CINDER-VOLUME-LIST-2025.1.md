Операции возвращают доступные проекту тома. Наличие API не гарантирует доступ к томам других проектов или успех запроса при любых полномочиях: действуют аутентификация, policy, параметры и фильтры. С microversion 3.31 некорректный фильтр от пользователя без административных прав вызывает ошибку запроса. Поддерживаются параметры пагинации; один ответ не гарантирует выдачу всех страниц.

- `GET /v3/{project_id}/volumes` — Список доступных томов с краткими сведениями; List accessible volumes, L283–346. Ответ содержит коллекцию volumes, идентификатор, имя и ссылки. Это отдельная операция от подробного списка и чтения одного тома.
- `GET /v3/{project_id}/volumes/detail` — Список доступных томов с деталями; List accessible volumes with details, L66–159. Подробные сведения относятся к доступным проекту томам; состав полей зависит от API microversion и прав доступа. Само наличие операции не подтверждает безусловную выдачу административных полей каждому пользователю.

Этот источник не подтверждает GUI, изменение или удаление томов, список backend pools, ёмкость хранилищ либо выполнение запроса на конкретном стенде.
